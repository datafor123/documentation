# Pivot table

Summarize a measure at the intersection of row and column groups.

1. Add **Charts → Pivot table** and select an **Analysis model**.
2. Add grouping fields to **Rows** and **Columns**.
3. Add numeric values to **Measures**. For example: Region in Rows, Year in Columns, and Net Sales in Measures.
4. Add **Filters** to limit the comparison period or population.
5. In **Style**, select a **Table style**, then review **Header**, **Content**, **Sub total**, and **Grand total**.

Use subtotals only where they help readers understand the grouping. A total for a ratio or distinct count may not equal the sum of visible cells; it depends on the measure definition.

Start with one row field and one column field. Add detail only after confirming the result. For a flat list of records or grouped values, use [Table](/documentation/Visualization/Table/).
