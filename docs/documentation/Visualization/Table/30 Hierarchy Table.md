# Tree table

Use a Tree table to present nested groups alongside additional values.

1. Add **Charts → Tree table** and choose an **Analysis model**.
2. Add the grouping levels to **Hierarchy fields**, from the broadest group to the most detailed.
3. Add the columns to display in **Fields**.
4. Set **Filters** as needed.
5. Choose a **Table style**, then format **Header**, **Content**, and **Grand total**.
6. Preview the report and check the expanded and collapsed hierarchy.

Example: Region → Store as hierarchy fields, with Net Sales in Fields.

If your data explicitly stores parent and child identifiers, use **Parent-child table**. Its Data panel has **Parent**, **Child**, **Caption**, and **Fields**. Bind the identifiers separately from the readable caption. Check for missing parents and circular relationships before using that structure.
