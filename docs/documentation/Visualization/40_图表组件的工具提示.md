# Tooltips for Chart Components

Tooltips show detail when readers point to a chart mark.

1. Select a chart and open **Data**.
2. Add supporting fields to **Tooltips** where the chart provides that slot.
3. Open **Style → Tooltip** and enable **Show Tooltip**.
4. Configure the options available for that chart. For Clustered column, these include **Sort**, **Show total**, **Show percentage**, and **Highlight hovered series**.
5. Preview the report and point to several marks, including a small value and a filtered result.

Keep the main chart focused on the comparison. Put identifiers, exact values, and secondary context in the tooltip. Include units and meaningful field names; do not make a tooltip the only way to understand an essential result on a touch device.

Page-wide tooltip appearance is available under **Page → Style → Tooltip**. Component options vary by chart type.
