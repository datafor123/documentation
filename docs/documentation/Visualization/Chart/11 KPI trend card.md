# KPI trend card

Show a metric, its trend, and its target together.

## Set up the data

1. Choose **Components → Charts → KPI trend card** and place it on the canvas.
2. Select the chart and choose an **Analysis model** in **Data**.
3. Use **+** beside each field slot to select the following fields, then click **Back**.

| Data slot | Choose |
| --- | --- |
| **Trend dimension** | Ordered field, usually a date. |
| **Actual value** | Measured result. |
| **Target value** | Target from data. |
| **Static target** | A fixed target when appropriate. |

Use **Filters** to restrict this component’s data. Check the result before styling it.

## Make it readable

Use **KPI**, **Marker value**, **Target label**, **Date**, and **Tooltip**.

Use consistent date granularity and compatible units for actual and target.

Save the report and use **Preview** to check labels, hover details, and the filtered result.

See [component filters](/documentation/Analysis/Component-Level-Filtering/) and [linked components](/documentation/Visualization/Filter-Subscriptions/).
