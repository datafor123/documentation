# Measure card

Show one headline metric with up to two comparison values.

## Set up the data

1. Choose **Components → Charts → Measure card** and place it on the canvas.
2. Select the chart and choose an **Analysis model** in **Data**.
3. Use **+** beside each field slot to select the following fields, then click **Back**.

| Data slot | Choose |
| --- | --- |
| **Measure** | The main number. |
| **Comparison #1 / Comparison #2** | Optional comparison measures. |

Use **Filters** to restrict this component’s data. Check the result before styling it.

## Make it readable

Use **Main value** for units and number presentation, **Comparison settings** for the comparison display, and **Layout** for placement.

Use a title that includes the business meaning and period. A card without context is easy to misread.

Save the report and use **Preview** to check labels, hover details, and the filtered result.

See [component filters](/documentation/Analysis/Component-Level-Filtering/) and [linked components](/documentation/Visualization/Filter-Subscriptions/).
