# GIS Map Settings

An administrator configures map services in **Settings → Data → Maps**. Report authors then select the appropriate map component and its map style.

| Service | Settings shown in Datafor |
| --- | --- |
| **Mapbox** | Geocoding URL, API key. |
| **OpenStreetMap** | Tile URL, Geocoding URL, Geocoding request interval (ms). |
| **Google Maps** | Tile URL, Geocoding URL, API key. |
| **Amap (Gaode)** | Tile URL, Geocoding URL, API key, Web service key, Security key. |

Use endpoints and keys supplied for your deployment. Tile URLs may contain coordinate placeholders such as **{z}**, **{x}**, and **{y}**. Geocoding converts location text into coordinates; it is separate from drawing the basemap.

1. Open **Settings → Data → Maps** with an administrator account.
2. Enter the settings for the service you intend to use.
3. Click **Save**.
4. Test a report with a known location and verify the map and marker position.

Each service offers **Clear geocoding cache**. Use it when correcting a configuration or stale location result, then retest the affected locations.

If the background is empty, check the selected service and tile access. If the background loads but a marker is wrong, check the source location, coordinate fields, and geocoding configuration.
