# Image map

Plot data at positions on an image, such as a floor plan or equipment layout.

1. Add **Charts → Image map** and choose an **Analysis model**.
2. Bind **X coordinate** and **Y coordinate** from your model.
3. Optionally bind **Marker size**, **Color**, **Tooltips**, and **Icon**.
4. Configure the image under **Style → Map settings**, then adjust **Marker settings** and **Data labels**.
5. Verify several known positions against the image before publishing the report.

Coordinates must use the same image reference and scale as the displayed background. Keep the source image dimensions with the dataset. Replacing or cropping the image may require adjusting the coordinates.
