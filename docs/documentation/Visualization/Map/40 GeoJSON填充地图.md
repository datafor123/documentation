# Filled map

Color geographic regions by a measure. The current catalog calls this component **Filled map**.

1. Add **Charts → Filled map** and choose an **Analysis model**.
2. Bind **Geographic field** and **Measure**.
3. Choose **Map** in Data and confirm that the field values match its regions.
4. Add supporting **Tooltips** and any **Filters**.
5. Use **Style → Data colors**, **Data picker**, **Region**, **Data labels**, and **Roam** to configure the display.

Check a few known regions against the source data. Decide whether an absolute total or a normalized measure best answers the question; large geographic areas can draw more visual attention regardless of their value.
