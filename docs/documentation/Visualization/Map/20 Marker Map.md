# GIS marker map

Place records on a geographic basemap.

1. Add **Charts → GIS marker map** and choose an **Analysis model**.
2. Bind **Geographic field** for location names, or **Longitude** and **Latitude** for coordinates available in your model.
3. Bind **Measure** for the metric and **Tooltips** for supporting detail.
4. In **Style**, review **Map Styles**, **Map markers**, **Data colors**, **Data labels**, and **Controls**.
5. Filter to a small known region and verify marker locations before expanding the scope.

For intensity rather than individual markers, choose **GIS heat map**. It provides the same location fields, with **Heat plot** and **Gradient** settings in Style.

Basemaps and geocoding depend on the configured map service. See [GIS Map Settings](/documentation/Visualization/GIS-Map-Settings/).
