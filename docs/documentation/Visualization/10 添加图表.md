# Adding Charts

Every data chart starts with a component, an analysis model, and field assignments.

## Add and configure

1. Click empty canvas space. Open **Components → Charts**.
2. Choose a type, then click the canvas to place it.
3. Select the chart. In **Data → Analysis model**, click **+**, select a model, and click **Back**.
4. Add fields to the chart's slots. A **Clustered column** uses **X-axis** for a category and **Measures** for a numeric value. **Legend** can split the values into series.
5. Check the resulting categories and values, then adjust **Style**.

![A configured column chart and its data slots](./images/current/column-data.jpg)

## Choose a useful type

| Question | Start with |
| --- | --- |
| Compare categories | Clustered column or Clustered bar |
| Follow a trend | Line or Area |
| Compare composition | Stacked charts, 100% stacked charts, or Pie |
| Show an exact value | Measure card or Table |
| Compare two numeric measures | Scatter |
| Examine a distribution | Histogram or Box plot |
| Explain a flow or breakdown | Sankey, Funnel, or Decomposition tree |

The catalog groups components by purpose. Scroll within **Charts** to see additional groups.

## Change data or type

Click a field slot to edit its selection. Hover a field and open **More function** for options such as sorting, aggregation, formatting, and drillthrough. Options depend on the field and component.

Use the toolbar's chart-type menu to convert a selected chart. Review the new slots and output afterward; different chart types need different field arrangements.

**Blank chart?** Select a valid model and fill the required slots. **Wrong totals?** Check filters and aggregation before formatting the chart.
