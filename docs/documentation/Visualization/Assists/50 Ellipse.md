# Ellipse

1. Add **Components → Assists → Shape**.
2. Open **Style → Shape → Type** and choose **Ellipse**.
3. Set **Fill and line**. Give the component equal width and height for a circle.
4. Use **Text** to add a short label if needed.

Use **Effects** for the component container. Keep decorative shapes behind the content they support.

See [Shapes](/documentation/Visualization/Shapes/) for other types and click actions.
