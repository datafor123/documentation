# Ellipse

1. In **Components → Assists**, click **Shape**, then click the canvas.
2. In **Style → Shape → Type**, choose **Ellipse**. Give the component the same width and height for a circle.
3. Set **Fill and line**, and add a short label under **Text** if needed.

Ellipse components from earlier versions keep working; **Style → Shape → Convert to shape** turns one into a Shape. See [Shapes](/documentation/Visualization/Shapes/) for all options and click actions.
