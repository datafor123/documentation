# Web page

Embed a page using a fixed address or a URL from data.

1. Add **Components → Assists → Web page**.
2. In **Data**, enter a **Custom Hyperlink**, choose **From repository**, or bind an **Analysis model** and **URL field**.
3. Use **Insert dynamic value** when the address needs a supported dynamic value. Review **Append filter values** if filter context should be passed to the destination.
4. Resize the component and test it in Preview.

![Web page address and data options](../images/current/web-page.jpg)

The destination must allow embedding and be reachable by the viewer. If it blocks embedding or requires a separate sign-in, use an **Open link** action instead. Check the final destination and passed values before sharing the report.
