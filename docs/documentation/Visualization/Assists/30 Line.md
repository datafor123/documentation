# Lines and arrows

Lines and arrows are types of the [Shape](/documentation/Visualization/Shapes/) component.

1. In **Components → Assists**, click **Shape**, then click the canvas.
2. In **Style → Shape → Type**, choose **Line**, **Arrow** or **Double arrow**. The **Divider** style preset gives a thin grey line in one step.
3. Set **Direction**: **Horizontal**, **Vertical**, **Top left to bottom right** or **Bottom left to top right**. Resize the component to change the length and angle.
4. In **Fill and line**, set **Line width**, **Line color**, **Line style** (Solid, Dashed, Dotted) and **Line ends** (Flat, Round, Square).

Line components from earlier versions keep working. Select one and use **Style → Shape → Convert to shape** to turn it into a Shape.
