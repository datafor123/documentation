# Rich Text

Use **Components → Assists → Rich text** for descriptions, notes, and explanations that need more than one text style.

## Write the content

1. Place **Rich text** on the canvas.
2. Double-click the component to start editing.
3. Enter the content and use the editor's formatting controls for the selected text.
4. Click outside the editor when finished and inspect the result in Preview.

## Set the defaults

Open **Style → Default text** to set the default font, line height, vertical alignment, and overflow behavior. Use **Effects** for the component frame.

![Rich text default-format settings](../images/current/rich-text.jpg)

Use a short heading and a small number of paragraphs. Give the component enough height for the finished content; check overflow at the report's normal viewing size.

For a lightweight label or parameter value with a single style, use [Text](/documentation/Visualization/Text/).
