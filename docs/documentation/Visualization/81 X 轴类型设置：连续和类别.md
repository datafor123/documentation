# X Axis Type Settings

The axis type controls spacing between values; it does not change the measure’s aggregation.

| Type | Meaning | Typical use |
| --- | --- | --- |
| **Categorical** | Each category occupies one position at equal spacing. | Regions, product names, or discrete period labels. |
| **Continuous** | Positions follow the numeric or time scale. | Numeric values or dates where the distance between values matters. |

For example, on a continuous time axis a three-day gap is wider than a one-day gap. On a categorical axis the displayed date labels occupy equally spaced positions. A continuous axis does not imply that missing observations are zero.

1. Select the chart and bind its axis field.
2. Open **Style → X axis**.
3. Where **Type** is available, choose the intended mode.
4. Check the first and last values, gaps, sorting, and label density in Preview.

The control depends on the chart and field type. A text category such as Region does not expose the same continuous-axis choices as a numeric or time field. Verify the field type in the model if the expected choice is unavailable.
