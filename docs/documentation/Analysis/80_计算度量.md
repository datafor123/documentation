# Calculated Measures

A calculated measure is evaluated at query time and can reference model Measures. Use it for reusable ratios, variances, time comparisons, running totals, and other calculations that must respond to the report's filter and grouping context.

Do not confuse a calculated measure with a calculated column:

| Object | Calculation level | Typical use |
| --- | --- | --- |
| **Calculated column** | Row level, using data source SQL syntax. | Normalize or derive a field before aggregation. |
| **Calculated measure** | Aggregated query context, using a model-level MDX expression that can reference Measures. | Ratios, period comparisons, shares, and reusable business calculations. |

Model-level calculated measures are created in the Analysis Model designer and can be reused by reports that use that model. For the current creation workflow, formula editor, quick-measure templates, and safety notes, see [Measures and Calculated Measures](/documentation/Model/Measures-and-Calculated-Measures/).

Measure references use syntax such as:

```text
[Measures].[Net Sales]
```

After creating or changing a formula:

1. Review Model diagnostics for unknown Measure references.
2. Confirm the formula's unit and display format.
3. Test the result at more than one grouping level.
4. Test time calculations with boundary periods and missing periods.
5. Compare representative results with a trusted calculation.

See [MDX Functions](/documentation/Advanced/MDX-Functions/) for the available function reference.
