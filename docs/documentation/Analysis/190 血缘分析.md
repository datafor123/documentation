# Lineage Analysis

Inspect the models and data sources used by a report before troubleshooting data or changing a dependency.

1. Open the saved report in Edit mode.
2. Click the toolbar action whose tooltip is **View item lineage**.
3. Read the graph and use **+** or **−** to adjust the view.
4. Click **Close** to return to the report.

![The saved example report, its model, and its data source](../Visualization/images/current/lineage.jpg)

Use the graph to identify which model to inspect when a chart’s data is unexpected. Follow it with a check of the actual field definitions, filters, and calculations; the dependency graph alone does not validate a result.
