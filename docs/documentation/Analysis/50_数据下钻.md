# Drill Down

Drill down changes a component from one hierarchy level to the next more detailed level, such as **Category L1 → Category L2 → Product**.

## Before you begin

The Analysis Model must contain a saved hierarchy whose levels are ordered from broadest to most detailed. See [Creating Hierarchies](/documentation/Model/Creating-Hierarchy/) for the current model workflow.

Use a level from that hierarchy in a component that supports drill down. Start with the broad level that report readers should see first.

## Drill into a data point

1. Open the report in preview mode.
2. On the component toolbar, click the control whose tooltip is **Click to turn on Drill down**.
3. Click a chart mark or supported data item. The component queries the next level in the hierarchy for that selection.
4. Continue until the required detail is visible.
5. Click **Drill up** on the component toolbar to return to the previous level.

## If drill down is unavailable

- Confirm that the field belongs to a hierarchy, not only to a Dimension.
- Confirm that another level exists below the current level.
- Check the level order in the Analysis Model and save the model.
- Refresh the report's model metadata after changing the hierarchy.
- Test with a data item that has members at the next level.

Changing a hierarchy can affect existing reports. Re-test reports that use renamed, reordered, or deleted levels before publishing the model.
