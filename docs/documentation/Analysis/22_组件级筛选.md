# Component-Level Filtering

Use a component filter to restrict one chart or table without adding a control to the page.

## Apply a condition

1. Select the component and open **Data**.
2. Click **+** in the **Filters** area at the bottom.
3. Find and select the dimension or measure to filter.
4. Choose the available **Filter type** and configure its condition.
5. Click **Apply**, then **Back**. Check both the result and the field listed under Filters.

![An inclusion filter selecting Year 2025](../Visualization/images/current/year-filter.jpg)

For a list filter, **Inclusion** keeps selected members and **Exclusion** removes them. Search narrows the member list; **Select all** and **Deselect all** help edit a large selection. Review the selected count before applying.

Date fields can offer **Relative** conditions. Use **Advanced** when a list selection does not express the required rule. Available types depend on the selected field.

## Change or remove a filter

Click its field under **Filters** to edit it. Hover the field and use its remove control to remove the condition. Removing a condition changes this component's query; it does not delete the underlying data.

The component's own filters are listed under **Own** in the toolbar's **Conditions** button, next to filter components, clicks on other charts and URL values. If a result is unexpectedly empty, open **Conditions** first: the empty component says *No data under the current filters* and offers **View conditions**.

For a condition readers can change on the canvas, add a [filter component](/documentation/Visualization/Filters/) and configure its linked components.
